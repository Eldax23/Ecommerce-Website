# 🛍️ Ecommerce Website

A simple e-commerce website built with **Angular** and styled with **Tailwind CSS**.

## Project Overview

The project is designed to provide a basic e-commerce experience, allowing users to view products, add them to their cart, and proceed with checkout.

## Features

- Display products in a list
- Add products to the shopping cart
- Remove products from the cart
- View cart details
- Responsive design using **Tailwind CSS**

---

## ⚙️ Installation

### Prerequisites

Make sure you have the following installed before proceeding:

- [Node.js 18+](https://nodejs.org/en/download) — required to run Angular and install packages
- [npm](https://www.npmjs.com/) — comes bundled with Node.js
- [Angular CLI](https://angular.io/cli) — install globally by running:

```bash
npm install -g @angular/cli
```

To verify your setup:

```bash
node -v
npm -v
ng version
```

---

### 1. Clone the Repository

```bash
git clone https://github.com/Eldax23/Ecommerce-Website.git
cd Ecommerce-Website
```

---

### 2. Install Dependencies

```bash
npm install
```

> This will install all packages listed in `package.json`, including Angular and Tailwind CSS.

---

### 3. Run the Development Server

```bash
ng serve
```

Then open your browser and navigate to:

```
http://localhost:4200
```

The app will automatically reload whenever you make changes to the source files.

---

### 4. Build for Production

To generate an optimized production build:

```bash
ng build
```

The output will be placed in the `dist/` folder, ready to be deployed to any static hosting provider (e.g. Netlify, Vercel, GitHub Pages).
